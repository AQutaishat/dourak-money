```json
  }
]
```

  builds also exist).

  file must genuinely exist in the built site: add it as `frontend/public/.well-known/assetlinks.json`
  (Vite copies `public/` verbatim into `dist/`, which is what's baked into `/srv`) and redeploy the

  pass was scoped to `mobile/`.
